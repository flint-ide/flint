# Code of Conduct

Flint adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone participating in the project: in issues, pull requests, discussions, and any other project space.

In short: be respectful, assume good faith, and focus on the work. Harassment and personal attacks are not tolerated.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately in one of these ways:

- open a private [GitHub Security Advisory](https://github.com/ODudek/flint/security/advisories/new) on this repository and say that it is a code of conduct report, or
- email the maintainer at the address listed on their [GitHub profile](https://github.com/ODudek).

Reports are handled confidentially. The maintainer will review the report and respond as described in the enforcement guidelines of the Contributor Covenant.
